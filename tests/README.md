# tests

Run with `uv run pytest tests/ --cov=src --cov-report=term`; `pyproject.toml`
sets the test paths, verbose output and the coverage floor.

- No mocking framework anywhere in this tree: `test_no_mocks.py` enforces the
  ban lexically, and absent/failing input is exercised with plain callables,
  real records and real temp directories.
- Unit surface: registry and invariants, intake staging, evaluator verdicts,
  canonical serialization and digests, replay reports, envelopes.
- Reproducibility: prepared declarations, envelopes, reports and bindings under
  `data/` are regenerated by `scripts/gen_examples.py` and asserted live;
  figures, formalism ledger and claim-ledger rows are re-derived from the
  running package rather than compared against prose.
- Regression batteries hold executed counterexamples for date, JSON,
  coherence, explanation and boundary findings.
- Scripts are additionally covered as subprocesses against real data, so a
  documented command that stops working fails the suite.

Coverage of `src` is enforced at the floor in `[tool.coverage.report]`.
Documentation recipes are checked through real native runs, not prose matching.
