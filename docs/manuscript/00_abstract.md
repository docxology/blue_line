## Abstract

The blue line answers one question: what must I keep working? It is a
stewardship instrument for maintained commitments — systems, obligations,
and relationships to past work. A declared file of commitments is read
against a versioned registry; each applicable commitment requires named
care signals, and the reading reports which were declared fresh at a review
date, which were missing, and which aged past a stated window. Intake is
fail-closed: malformed input is set aside with notes, and an empty scan set
is an explicit outcome rather than a pass. The verdict is a
declaration-coverage statement and never a warranty, SLA, availability
guarantee, or proof of maintenance. I describe the instrument's
architecture, its verdict semantics, and the boundaries it refuses to
cross.
